# About
{: .no_toc }

**Image Retrieval arXiv Daily** is an automatically maintained index of new arXiv
papers on image retrieval and visual search in computer vision. Every day a GitHub
Actions workflow queries the arXiv API, sorts the results into research topics,
looks for the authors' code and republishes this site.

## How papers are collected

1. **Query.** For each topic, the arXiv API is asked for the newest papers whose
   *title or abstract* contains one of the topic's search phrases, restricted to
   the arXiv categories listed for that topic [below](#research-topics), such as
   cs.CV, cs.IR and cs.MM.
2. **Merge.** Results are merged into one database. A paper that matches several
   topics is stored once and listed under each of them; when a recent paper is
   revised, its stored title, authors and comments are refreshed.
3. **Link code.** Repository links (GitHub, GitLab, Codeberg, Bitbucket and
   anonymous review links) are read from the abstract and the author comments.
   For papers without one, the [Hugging Face Papers](https://huggingface.co/papers)
   API is asked for a linked GitHub repository. A weekly job re-checks recent
   papers, because code is often released after the preprint.
4. **Publish.** The database, abstracts and the [Atom feed]({{ '/feed.xml' | relative_url }})
   are committed to the repository and GitHub Pages rebuilds the site.

Dates on the papers page are arXiv **submission dates** of the first version
(UTC). Papers are grouped by that date; a **New** badge marks papers added in the
most recent update, and *Revised* shows when a later version was posted.

## Research topics

Each phrase is matched as an exact phrase in titles and abstracts, ignoring case.
Hyphens count as spaces, so `sketch-based` also finds "sketch based"; a phrase
prefixed with `ti:` is matched in titles only. Select a topic name to see its
papers.

## Using the papers page

- **Search** matches titles, authors, arXiv IDs, comments, journal references,
  categories and topic names. It ignores case and accents, requires every word to
  match, and accepts quoted phrases such as `"composed image retrieval"` and arXiv
  URLs. Press <kbd>/</kbd> to jump to the search box.
- **Filters** narrow the list by topic, period and code availability. *Latest
  update* shows the papers added by the most recent run; the other periods count
  submission days back from the newest paper in the collection. Topic counts
  update with the other filters.
- **Links.** Every view has its own URL, so a filtered list can be bookmarked or
  shared. Each paper links to its arXiv page and PDF and, when a repository is
  known, to its code; it shows the abstract on demand and can copy a BibTeX entry.
- **Feeds and data.** Subscribe to the [Atom feed]({{ '/feed.xml' | relative_url }})
  for new papers, or download the paper list as [JSON data]({{ '/data/papers.json' | relative_url }}).
